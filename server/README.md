# server/ · AI 直播副驾驶 后端

> **状态：规划中，尚未开发。** 本目录先立结构约定，代码从零开始。

## 职责边界（只有这四件事上云）

| 模块 | 干什么 | 为什么必须上云 |
|---|---|---|
| **账号 / 订阅** | 注册登录、订阅档位与配额 | 计费必须可信 |
| **LLM 代理** | 翻译 + AI 应答（DeepSeek V4 Flash） | 保护 API Key；端侧拿不到大模型 |
| **弹幕 WS** | 平台弹幕 → 境外节点 → 本服务 → App | 境内外链路中转 |
| **设备 / 配置** | 话术库、背景素材、版本与灰度 | 多端一致 |

**不上云的**：抠像、数字人、TTS、ASR、编码推流 —— 全部端侧跑，
所以服务器没有 GPU，成本只有 LLM token。

## 技术栈（拍板）

- **NestJS + TypeScript**（Node 运行时）
- PostgreSQL（账号 / 订阅 / 话术库）+ Redis（配额计数、弹幕队列）
- 与端侧的实时通道：WebSocket（弹幕回流、AI 应答下发）

## 与端侧的接口约定（待细化）

- **翻译/应答**：`POST /llm/respond`，请求带会话上下文 + 目标语言，服务端返回
  目标语言文本（端侧 TTS 念出，混进推流音频）。
- **弹幕**：`WS /danmaku`，下行 `{平台, 用户, 原文, 译文, AI是否已回}`。
- **配额**：按分钟/条数计，**对外不出现 token 字样**。

## 平台接入备忘

- Kick 最友好（读✓发✓）；Twitch 读✓发✓（超速后 bot 被忽略 1h）；
  YouTube 读✓发✓但配额卡死（**必须用 streamList 推送式**）；
  TikTok 官方零弹幕 API → 降级为播报型。
- 「有电商 API」≠「有直播互动 API」，别混。

## 安全红线

- 平台 token / 推流密钥 = bearer secret：加密存、不进日志、可撤销。
- 所有对外接口按订阅档位限流；LLM 层做提示词缓存 + 分层应答压成本。
